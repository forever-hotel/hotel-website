# Website photographs

## Generated and optimised variants

At the user's request, missing facility images were generated using the built-in
image-generation tool. Each is a generic illustrative concept, not a verified
photograph of this property, and carries a visible label in the UI:
`illustrative-spa.webp`, `illustrative-gym.webp`, `illustrative-meeting.webp`,
`illustrative-function.webp`, and `illustrative-karaoke.webp`.

`forever-city-room-enhanced.webp` is an AI-enhanced reconstruction of the original
`forever-city-room.jpg`, prompted to preserve the room layout and furnishings.
It is visibly identified as enhanced; fine textures/details can differ from the
source. It is 1536×1024, approximately 103 KB. Generated facility files are also
1536×1024, roughly 180–295 KB, saved at WebP quality 86.

`forever-city-pool.webp`, `forever-city-dining.webp`, and
`forever-city-room-romantic.webp` are quality-90 WebP conversions of the original
property photographs, without generative changes. The larger daytime pool photo
now replaces the small night image in the hero. Original JPEGs remain unchanged.
This section supersedes the older placeholder notes below.
